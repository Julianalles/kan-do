# Mobile board rules (≤767px: swipe between pages, edge-scroll during drag)

- Swipe between pages: `composables/useBoardSwipe.ts` (pointer events, touch only) locks a touch to one axis after ~10px; vertical stays native scroll (`touch-action: pan-y` on `.board-container` **and** each column page, since touch-action ends at the nearest scroll container), horizontal sets a transient `offsetPx` (class `.board.swiping { transition: none }`) and commits on >25% width or >0.4px/ms. It stands down via `isEnabled` while `isDragging`; never `preventDefault` touches (dnd-kit needs them)
- **No tabs, no dock (#470, ADR 017):** the phone board has no column tabs and no action dock. Swipe and the drag edge-scroll are the only ways between the three column pages; `.board` carries `data-mobile-page="0|1|2"` (Offen, Jetzt + Wartet, Erledigt), and `focusin` on a control of an off-screen page makes that page active (the keyboard / screen-reader path the tabs were). The board opens on page 1 while a task sits in Jetzt, else on page 0 (kd#191; read once at setup in `Board.vue`). The page bottom padding, the sticky add-task bar, the Erledigt CTA (`.column-footer`: on the phone not sticky since #297, it follows the list at the cards' width; the page's own bottom padding clears the bar, so the offset is not added again; desktop keeps `position: sticky; bottom: 0`) and the toasts clear the floating app bar by `--phone-bar-offset` (`assets/css/app-nav.css`); the bar fades out and ignores pointers while a card is dragged. A touch that starts on the bar never swipes the board (the bar is outside `.board-container`)
- Edge-scroll during drag: pointer dwelling ≥650ms in the 72px edge zone triggers a column switch; constants `EDGE_HOLD_MS` / `EDGE_ZONE_PX` in `Board.vue`
- **Two places, one strip (#354, epic #334):** "Alle" (`/all`) and "Heute" (`/tasks`) are two paths of one page (`pages/tasks.vue`, `alias` + a fixed page key), so `Board.vue` stays mounted and Offen is the same column in both, headed "Heute" on "Alle" and "Offen" on "Heute" (#375, `openColumnTitleKey`; the header fades between the two with the place move). `lib/boardPlace.ts` holds the path helpers and the current path (mirrored from the live router route by `plugins/board-place.client.ts`, sync); read the place through `useBoardPlace()`. A link between the two places needs vue-router's `force` (`boardPlaceLocation(place)`, `todayLocation()`): alias to original is a redundant navigation otherwise and does nothing. A sheet or the add flow opens under `basePath` / `boardBasePath()`, never a hard-coded `/tasks/…`, so it closes back to the place it was opened on. Route names stay `tasks`, `tasks-id`, `tasks-add` on `/all`.
- **Pages per place:** the strip index is -1 "Meine Aufgaben", 0 Offen, 1 Jetzt + Wartet, 2 Erledigt (`stripPage` in `Board.vue`); "Alle" shows -1 and 0 (two dots), "Heute" 0 to 2. `data-mobile-page` is the index within the place (Heute 0|1|2 as before, "Alle" 0|1), `data-place` says which place shows. The board stays 300% wide: the "Meine Aufgaben" page hangs one container width left of it (`position: absolute; right: 100%`, `board.css`), so Heute's transforms and baselines are unchanged. A swipe, the edge-scroll and `focusin` never leave the place (the edge-scroll and its arrows work inside "Alle" too, #355: a held card is carried between "Meine Aufgaben" and Offen); only the app bar does (on "Alle" its pill is the normal `Alle | Heute | Statistik`, the green "Weiter zum Board" is gone, #454; the capacity echo's `BoardCapacityDock` is a fixed bar above the app bar on a phone), in one move of `--place-move` on `--place-ease` (`data-place-moving` on `.board` meanwhile). "Alle" opens on "Meine Aufgaben", Heute on Offen when coming from "Alle". The side out of view is `inert` and hidden by the unlayered rules at the end of `board.css` (desktop `display: none`, phone `visibility: hidden`); a rule that must beat a column's `flex` / `relative` utility cannot live in the components layer.
